#  Setup and Use a Firewall on Windows

## Objective

To configure and test basic firewall rules for managing network traffic.

## Tool Used

Windows Defender Firewall with Advanced Security

## Steps Performed

1. Opened Windows Defender Firewall using wf.msc.
2. Viewed existing inbound firewall rules.
3. Created a new inbound rule to block TCP port 23 (Telnet).
4. Verified that the rule was successfully added.
5. Tested the configuration using Command Prompt.
6. Removed the test rule to restore the original configuration.

## Result

Successfully created, tested, and removed a firewall rule blocking Telnet traffic on port 23.

## Conclusion

Firewalls help secure systems by monitoring and controlling incoming and outgoing network traffic based on predefined security rules.
